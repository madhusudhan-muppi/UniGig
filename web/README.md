# UniGig web app

The Next.js app for UniGig. See the [main README](../README.md) for what UniGig is, setup, demo accounts and a walkthrough.

Quick start (Node.js 22+):

```bash
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Then open <http://localhost:3000> and log in as `alice@uni.edu` / `password123`.
